# 🛡️ PhishGuard AI - Detector Inteligente de Phishing

PhishGuard AI es una aplicación interactiva desarrollada en **Python** y **Streamlit** que utiliza el modelo **Google Gemini API** para analizar correos electrónicos en tiempo real, detectando vectores de ataque, ingeniería social y amenazas de seguridad.

---

## 🚀 Características Clave

* **Análisis Predictivo:** Evaluación de nivel de riesgo (Bajo, Medio, Alto/Crítico).
* **Desglose de Amenazas:** Explicación técnica detallada de por qué un mensaje es legítimo o sospechoso.
* **Recomendaciones Claras:** Guía de acción inmediata para el usuario final.
* **Interfaz Dinámica:** Diseñada con Streamlit para una experiencia limpia e interactiva.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Python 3.12+
* **Frontend / UI:** Streamlit
* **IA / LLM:** Google Gemini API (`google-genai`)
* **Control de Versiones:** Git & GitHub
